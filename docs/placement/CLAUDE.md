# docs/placement: spec for the Placement Hub prototype

This folder is the **spec**, not the code. The code it specifies lives in `products/placement/`, and its brief is `products/placement/CLAUDE.md`. Read that first. The prototype the case study embeds is a separate app, `products/placement-hub`, which this spec does not describe.

- `spec/`: acceptance, state model, scenarios, screen map, components, tokens, reference screens
- `docs/prototype-decisions.md`: decisions log
- `KICKOFF.md`: the first prompt for Claude Code
